# Publishing Notes

This repository is intended to be public. Keep private API keys, credentials, local absolute paths, private MCP endpoints, runtime logs, and user data out of commits.

Verify model IDs and plan availability before publishing routing changes. Model availability is time-dependent.

For Codex, the shipped Free/Go-oriented default is GPT-5.6 Terra at the time of this release. OpenAI currently documents Terra as available in Codex for Free and Go users; API pricing and model access are separate.
