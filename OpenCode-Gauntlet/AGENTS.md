# OpenCode Gauntlet Project Instructions

Use `.opencode/agents` and `.opencode/commands` as the authoritative Gauntlet implementation.

This package is project-agnostic. Do not assume Roblox, Blender, a browser, a game engine, or any specific MCP exists.

Use connected tools only when they are actually available.

Never treat source-code existence or a successful build as player/user-facing proof.

The main loop must continue through implementation, build/run, natural-user testing, evidence review, diagnosis, fixes, replay, and fresh re-judging.
