# Contributing

Keep the generic editions project-agnostic. Put application-specific integrations in separate examples rather than hardcoding them into the core packs.

When changing model routing, update the appropriate model-routing documentation and explain why the role benefits from the chosen model. Reuse strong models where useful instead of adding a model purely for variety.

Preserve evidence integrity: missing evidence is unresolved, stale evidence cannot validate changed behavior, and build success alone is not completion proof.
