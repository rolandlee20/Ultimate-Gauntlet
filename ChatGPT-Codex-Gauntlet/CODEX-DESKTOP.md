# Using the Codex Desktop Edition

1. Open this repository folder in the **ChatGPT Desktop app** and switch to **Codex**.
2. Trust the repository when prompted. Project-local `.codex/` configuration is loaded only for trusted projects.
3. Codex automatically discovers project `AGENTS.md`, `.codex/agents/`, and `.agents/skills/`.
4. Fill out `MISSION-PROMPT.md` or paste the mission directly in the Codex session.
5. Invoke `$gauntlet`.

The project-local setup is designed for the Desktop app but uses the same Codex configuration model supported by other local Codex clients.
